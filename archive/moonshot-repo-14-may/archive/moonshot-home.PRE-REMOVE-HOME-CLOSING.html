Deployment options

UX governance ships two ways.

UX governance can ship two ways into the agentic stack. Both are valid; most production deployments use both together.

Option A · Runtime agents

Guardian Agents in production

  • Heuristics Agent and Accessibility Agent run alongside the rest of the agent system.
  • Audit outputs as the system operates — interfaces, decisions, escalations, generated content.
  • Surface violations to humans through the same approval and escalation channels as domain agents.
  • Log every check, feeding the trust calibration loop over time.
  • Catches drift, regressions, and failure modes that only appear in operation.
Option B · Skills and SDLC checks

UX governance in the development pipeline

  • Governance encoded as Claude skills (e.g., "use the UI kit," "WCAG 2.2 AA contrast required," "follow Nielsen Norman 10").
  • Skills invoked during agent prototyping — output constrained at generation time, not corrected after.
  • Dev-time linters and CI checks block violations before merge.
  • Lower runtime cost. Faster developer feedback loop.
  • Catches what's catchable early — before it ever reaches production.

Most production deployments will use both. Design-time constraints catch what's catchable early; runtime auditing handles what only shows up in operation. UX orchestration covers both layers.

Both deployment models are endorsed by Infios AI engineering.

What the company gains

Horizontal action as infrastructure, not overhead.

Every product Infios ships now has an AI layer. What it tells the user, what it withholds, what it asks before it acts — that is horizontal work, cutting across every pillar. It is not a skin on top of the logic; it is the logic, made legible. A team that owns those decisions needs the same kind of tooling the engineering and data teams already have: agents running in the background, surfacing signal, closing loops that currently stay open.

The WMS prototype proves one version of that. The Guardian and Horizon layers show the full picture: horizontal intelligence that runs on cadence, responds to workflow events, and feeds back into itself. The team does not just get faster. The system gets smarter every time it is used.

That is the shift. The horizontal layer stops being a department that reviews work at the end and becomes the seam that makes product, engineering, and commercial decisions safer from the start — because the knowledge is always current, the quality is always checked, and the client's voice is always in the room.

AI Experience Layer

Orchestration

The seam between the human and the team. One agent owns it. There is no second.

AC
Archer Chat Agent
Orchestrator. The only agent that addresses the human user — directly, and by design.
The only agent that speaks to the user — every approval, escalation, and audit-log entry passes through here.
What it does
Routes user intent to the right sub-agent based on message and active mode (operational or analysis). Tags every proposed action urgent or standard at generation time, so the escalation path is decided before anyone reads the description. Manages session state, writes the audit log, consolidates joint recommendations into a single proposal, and enforces the four-condition supervisor-unavailability escalation model.
Talks to
Receives from Shift Intelligence (anomaly alerts), all eight domain agents (Tier 2 proposals), all three analytical agents (findings).
Sends dispatch instructions, approval and rejection decisions, deactivation signals.
Single approval gate. No agent reaches the human except through this one — and no Tier 2 action executes without an approved record in the audit log first.

What the company gains

UX as infrastructure, not overhead.

Every product Infios ships now has an AI layer. What it tells the user, what it withholds, what it asks before it acts — that is UX work. It is not a skin on top of the logic; it is the logic, made legible. A team that owns those decisions needs the same kind of tooling the engineering and data teams already have: agents running in the background, surfacing signal, closing loops that currently stay open.

The WMS prototype proves one version of that. The Guardian and Horizon layers show the full picture: design intelligence that runs on cadence, responds to workflow events, and feeds back into itself. The team does not just get faster. The system gets smarter every time it is used.

That is the shift. UX stops being a department that reviews work at the end and becomes the layer that makes product, engineering, and commercial decisions safer from the start — because the knowledge is always current, the quality is always checked, and the client's voice is always in the room.

Product & Engineering

Quality, accessibility, and interaction consistency are validated before work reaches review. Teams move faster because the checks are built into the process — not added at the end.

AI Experience Layer

UX thinking is present in the AI architecture from the start — not bolted on after engineering. What the system says, asks, and withholds is designed, not defaulted.

Scale Without Drift

Every project adds to the shared context every agent reads from. The team accumulates institutional knowledge rather than losing it — and a new hire reaches full context in days, not months.
