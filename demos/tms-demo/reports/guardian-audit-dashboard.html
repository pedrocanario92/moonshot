Guardian Audit — TM Operations Dashboard (TMS)

A single-screen command-centre for a transportation manager at shift start: a 7-button toolbar, a 6-tile KPI bar, a live route map, a real-time exceptions feed with inline Approve / Dismiss, a carrier performance table with sparklines, and a 30-day cost-trend chart — all on screen at once, with no calm state.

Seven load-bearing failures — six on the Heuristics agent (H1, H2, H3, H4, H5, H6) and one on Accessibility (A3 Timing Adjustable). The dashboard cannot proceed to development until the blocking issues are resolved. The advisory FAILs and WARNs below should be addressed in the same pass.

Blocking issues & suggested fixes
H1
~20+ elements above the fold.
Fix: Make the exceptions feed the single default surface; move KPIs, map, carrier table, and cost chart behind tabs or a progressive "expand" so ≤ 6 elements show at rest.
H2
7 persistent primary toolbar actions.
Fix: Keep one primary ("New Shipment") in the toolbar; collapse Export/Filter/Sort/View Report/Configure into an overflow menu. Target ≤ 3 visible primaries.
H3
11+ competing information chunks.
Fix: Show one zone at a time (default to the exceptions feed); let the manager drill into map / carrier / cost views rather than holding all in working memory.
H4
Decorative deltas, sparklines, pulsing pins, flashing "live" label.
Fix: Remove zero-decision-value chrome; surface a metric only when it changes a decision, and replace animation with a static "updated 09:48" timestamp.
H5
No calm state; nothing owns first fixation.
Fix: Introduce a calm state whose single focus is the highest-severity exception; everything else is secondary until summoned.
H6
Selected exception has no single primary action.
Fix: On selection, promote "Approve reroute" as the one dominant action and demote the persistent toolbar so the busy state has exactly one primary.
A3
Live refresh can displace an in-progress Approve/Dismiss.
Fix: Pause/queue the auto-refresh while a row's action is focused or open, and never re-order or remove a row that has a pending decision.
